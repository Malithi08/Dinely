# Dinely

A Flutter app for restaurant table reservations and queue management with three user roles: Customer, Staff, and Manager.

## Features

- Customer signup and login
- Staff and manager login
- Multi-restaurant support (each staff/manager assigned to one restaurant)
- Firebase Auth + Firestore for user profiles and roles
- Role-based post-login routing

## Tech Stack

- Flutter (Dart)
- Firebase Authentication
- Cloud Firestore
- Google Fonts (Playfair Display, Poppins)
- Font Awesome Flutter
